# Security policy

Report a suspected vulnerability privately through
[GitHub's vulnerability reporting form](https://github.com/BlushRins/SWAPPR/security/advisories/new).
Include the affected version, the feature involved, and the impact. Keep
credentials, private student data, and session tokens out of the report.

The latest `main` branch receives security fixes. See the
[credential incident runbook](docs/credential-incident.md) for an exposure and
[deployment instructions](docs/deployment.md) for applying and verifying fixes.
